SPARKON MUSIC FESTIVAL · RECORD v56
27인치 iMac 전시용 / 한 팀 체험 / 모바일 큐레이션

1. 체험 흐름
메인 원본 모션 → 안내 → 3·2·1 → 8팀 중 랜덤 1팀의 하이라이트
→ MY FIRST SPARK RECORD + QR → 모바일에서 아티스트 인사/무대/추천곡/비하인드/공식 SNS/기록 저장.
하이라이트 음원은 팀별 제공된 원본 8개를 사용합니다.
멤버 카드 문구는 SPARKON 전시를 위해 구성한 창작 문구입니다.

2. 무반응 초기화
안내·카운트다운·결과 등 정적인 화면에서 클릭, 마우스 움직임,
터치, 스크롤, 키보드 동작 없이 20초가 지나면 처음으로 돌아갑니다.
하이라이트 재생 중에는 14~28초짜리 음원이 중간에 끊기지 않도록
자동 초기화를 유예하고, 끝나면 결과 화면으로 넘어갑니다.
결과 화면 QR도 약 20초 동안 아무 동작이 없으면 닫힙니다.
관리자/권한 설정 화면에서는 자동 초기화가 멈춥니다.

3. 반드시 확인할 QR 주소
ZIP의 record.html과 assets/ 파일을 공개 HTTPS 웹 서버
(예: GitHub Pages의 https://계정.github.io/sparkon/)에 올리세요.
데스크톱 index.html만 로컬에 복사해도 폰에서 열리는 모바일 사이트가
자동으로 업데이트되지는 않습니다.
기존 기본값: https://seuuuuuuuung.github.io/sparkon/record.html
그 주소의 실제 배포 여부는 본 패키지만으로 보장되지 않습니다.

관리자: Control + Option + Shift + A
→ QR 기본 주소를 배포된 /record.html HTTPS 주소로 맞춤
→ [모바일 기록지 배포 테스트 열기]를 통해 페이지 확인
→ 실제 iPhone/Android 카메라로 결과 화면 QR 스캔
→ 아티스트 이름·곡·멤버 인사·링크 확인.
모바일 공식 채널은 팀별 Instagram, YouTube, X 계정으로 직접 연결됩니다.
기록지에서는 감상 선택형 질문과 TMI 섹션을 제외했습니다.
QR 데이터는 URL의 # 뒤에 붙으며, 별도 서버에 관람자 카메라 영상은
올라가지 않습니다.

4. 27인치 iMac / 음악 점검
Chromium 계열 브라우저에서 화면 전체 표시 후 권한을 확인하세요.
스크린은 16:9 비율 유지와 비율별 여백 조절을 적용합니다.
원본 SPARKON 모션 영상과 아이덴티티, 분홍·라임 열화상 필터 유지.
관리자에서 카메라·마이크 권한, 스피커 소리 테스트, 출력 음량을
전시용 헤드셋에 맞게 점검하세요.
음원이 깨지는 경우 헤드셋/맥 출력의 이중 증폭, 출력 장치 및
관리자 출력 음량을 점검해 주세요.

5. 무게를 줄인 방식
사용하지 않는 세그멘테이션 라이브러리(약 28MB)와
이전 모션 영상/중복 이미지, 인라인 폰트·MP3·이전 아트 자산을
배포본에서 제외했습니다. 실시간 무대와 주먹 인식의 원본
핵심 라이브러리, 8팀 음원, 4K 원본 모션은 유지했습니다.
무대/손 인식의 큰 리소스는 최초 체험 진입시에 요청합니다.
추가 압축은 기존 모션의 글자·그래픽 화질에 영향을 줄 수 있어
하지 않았습니다.
