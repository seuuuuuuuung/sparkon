SPARKON — MY FIRST SPARK RECORD v51 (27-inch iMac)
2026.11.20 수정본 / 27인치 화면 배율 및 버튼 전환 오류 수정

[실행]
1. ZIP 압축을 해제하고 폴더 구조를 유지합니다.
2. 27인치 iMac에서 index.html을 Chrome으로 엽니다. 전체화면은 Mac에서 Control + Command + F로 전환할 수 있습니다.
3. 첫 화면에서 Space / Enter / 화면 클릭 한 번: 메인 → 안내. 이때 카메라·마이크 권한창이 뜨면 허용합니다.
4. 한 번 더 누르면 3·2·1 카운트다운 → 인터랙션으로 이어집니다. 버튼을 길게 누르더라도 화면 두 개를 건너뛰지 않습니다.
5. 센서 권한을 거부하거나 카메라가 없어도 안내/카운트다운 화면 전환은 가능합니다. 다만 손 인식은 작동하지 않으므로 전시 시작 전에 반드시 권한을 허용해 주세요.
6. 화면 비율은 16:9로 자동 맞춤(27인치 2560×1440, 5K iMac의 2560×1440 논리 해상도 및 브라우저 축소 창 포함). 화면 바깥으로 잘리지 않습니다.
7. 권한 설정창을 다시 열거나 닫으려면 Control + Option + Shift + P. 거기서 카메라·마이크 재연결이 가능합니다.
8. Ctrl + Alt + Shift + A (Mac: Control + Option + Shift + A)로 관리자 열기.
9. QR 기본 주소는 현재 GitHub Pages의 https://seuuuuuuuung.github.io/sparkon/record.html 로 설정되어 있습니다. 이전에 다른 주소를 저장했다면 관리자에서 이 주소로 고쳐 저장하세요.
10. 관리자 > 스피커 소리 테스트로 먼저 음원을 들어보세요. 브라우저에 별도 스피커 권한 수락은 없으며, 클릭/키 입력으로 오디오 재생 제한을 해제하도록 수정했습니다.

[v51 수정 내용]
- 27인치 iMac의 16:9 화면에 맞춰 스테이지 크기를 화면 너비/높이에 자동 맞추고, 레이아웃이 잘리지 않도록 조정.
- 기존 시작 화면을 덮던 초기 권한 안내창을 숨기고, 사용자가 첫 버튼을 누르면 센서 연결을 별도로 시도하도록 변경.
- 센서 연결 및 오디오 초기화가 늦거나 거부되어도 메인 → 안내 → 카운트다운 화면 이동은 정상 작동.
- 클릭 영역을 스테이지 전체로 일원화. Space / Enter / 숫자 키패드 Enter 대응, 반복 입력/빠른 연속 입력 방지.
- 기존 모션, 필터, 가이드 그래픽, 기록지 디자인, 아티스트/음악 데이터는 변경하지 않음.

[QR / 모바일 배포 주의]

assets/sparkon-mobile-v41.js, assets/logo.png, assets/record_web_reference.png 등을 HTTPS 웹사이트(GitHub Pages 등)에 함께 배포합니다.

사용 중인 GitHub Pages: https://seuuuuuuuung.github.io/sparkon/record.html
**같은 저장소의 /sparkon/ 경로를 유지한다면 위 QR 링크를 그대로 사용합니다.**
저장소나 record.html의 경로가 달라질 때만 관리자에서 QR URL을 변경하세요.
외부 HTTPS 배포 전에는 다른 기기에서 스캔 가능한 QR이 생성되지 않습니다.
기록 데이터는 URL의 # 부분에만 담기며, 동영상/카메라 화면/원본 음성은 저장하지 않습니다.
모바일 결과지는 QR에 포함된 기록만으로 재구성되므로 별도 기록 서버는 필요 없습니다.
모바일 디자인 확인: record.html?demo=1 (임의의 예시 결과, 실제 체험 아님).
기록 URL은 자동 만료되지 않습니다. 웹 QR 표시 화면만 60초 후 메인으로 복귀합니다.
